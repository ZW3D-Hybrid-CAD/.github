# ZW3D — hybrid CAD before the CAM workspace

ZW3D keeps one named board on the desk: the live hybrid model, the surface in front of you, and a short note the next CAM seat can read. Extra products wait for their own title.

## Session Card

| Slice | What you do in ZW3D | What remains |
|-------|------------------------|--------------|
| Arrival | Open ZW3D and name today's product desk | A titled CAD CAM file |
| Focus | Keep only live solids on the ZW3D board | A short surface list |
| Check | Read ZW3D CAM workspace before a large hybrid change | A confirmed product desk |
| Handoff | Mark finished surfaces inside ZW3D | A note for the next CAM seat |

## How ZW3D Sits

ZW3D does not replace the unlabeled solid dump, the separate CAM seat, or the second CAD file you already keep. It sits beside them as a named product desk for one job: which hybrid CAD is live, which solid surfaces still match the CAM workspace, and what the next CAM seat should read.

If two people share a product PC, each keeps a ZW3D style of their own. Extra models wait for their own title instead of crowding the live hybrid.

A first visit should be one short surface pass, then the same ZW3D product desk the next day. That is enough to see if the named CAD CAM file holds.

## Traffic Light

| Signal | On the ZW3D board | What you do |
|--------|----------------------|-------------|
| Green | Named product desk, short live hybrid | Continue the same solid surfaces |
| Amber | CAD and CAM mixed from two products | Split the workspace before a large change |
| Red | No title, no note, solids and surfaces unlabeled | Stop and name the product desk first |
| Clear | Handoff written, live surfaces few | Close ZW3D and leave the product desk |

## Open Order

1. Open the last ZW3D product desk, not a new empty CAD CAM file.
2. Read the solid surfaces and the last handoff.
3. Finish one visible CAM workspace pass inside ZW3D.
4. Write what changed, then close with fewer unlabeled solids than you found.
5. If the hybrid feels crowded, drop anything that belongs to a different ZW3D product.
6. Confirm ZW3D hybrid CAD still sits on the model you keep.

| Shop | Named CAD CAM file kept apart from unlabeled solids |
| Handoff seat | CAM after CAD kept on the same product desk |

## After a Week

A week in ZW3D is not a larger unlabeled solid-and-surface pile. It is the same title, a shorter live hybrid, and a note that still makes sense before CAM after CAD. Take finished surfaces off the live set so the next visit starts on the product desk that is still open.

Other programs stay where they are. ZW3D only keeps the path back: desk name, hybrid CAD, CAM workspace, handoff.

Leave ZW3D with a quieter product desk than the one you opened. The next visit should start on that named CAD CAM file, not in a search.

## Sign-off

- [ ] The ZW3D workspace name is short enough to scan
- [ ] Only live solids and surfaces sit on the hybrid
- [ ] A second CAM seat can read the product handoff
- [ ] The last ZW3D CAD CAM file still opens after a restart
- [ ] Finished surfaces are off the live ZW3D set
- [ ] The ZW3D summary still matches the CAM workspace on the board

## Field Note

ZW3D is easier to trust when the product desk stays smaller than the unlabeled solid-and-surface pile it came from. Name the CAD CAM file, keep the live hybrid, finish one visible CAM pass, and write what changed.

The same loop fits a shop hybrid, a product desk handoff, or a shared PC. Open the last ZW3D model and continue. Do not rebuild the surface-solid hybrid from scratch.
